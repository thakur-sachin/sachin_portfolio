# sachin_portfolio

Personal site for Sachin Thakur, robotics and machine learning engineer: <https://thakur-sachin.github.io/sachin_portfolio/>

Plain HTML, CSS, and JavaScript with no build step; GitHub Pages serves it from `master`.

- `index.html`: all content
- `assets/site.css`: styles (design tokens at the top)
- `assets/site.js`: the hero's inverse-kinematics arm
- `img/`: project photos
- `Sachin_Thakur_Resume.pdf`: the résumé linked from the site; replace this file to update it

Preview locally with `python3 -m http.server` and open <http://localhost:8000>.
